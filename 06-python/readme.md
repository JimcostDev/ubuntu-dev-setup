# 06 - Python

Configura el entorno de desarrollo de Python para Ubuntu.

## Objetivos

- Instalar las herramientas necesarias para desarrollar con Python.
- Configurar `pip`.
- Instalar `venv`.
- Instalar herramientas básicas.
- Verificar la instalación.

## Scripts

```bash
./01-install.sh
```

### 02-post-install.sh

```bash
./02-post-install.sh
```
