# 03 - Visual Studio Code

Este módulo instala Visual Studio Code desde el repositorio oficial de Microsoft.

## Objetivos

- Agregar el repositorio oficial de Microsoft.
- Instalar Visual Studio Code.
- Verificar la instalación.

---

## Script

### 01-install.sh

```bash
./01-install.sh
```

---

## Resultado esperado

Al finalizar:

- Visual Studio Code estará instalado.
- El comando `code` estará disponible desde la terminal.
- Podrás iniciar sesión para sincronizar extensiones y configuración.
