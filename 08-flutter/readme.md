# 08 - Flutter

Instala Flutter SDK (incluye Dart) desde el repositorio oficial.

## Características

- Instalación desde Git.
- Configuración automática del PATH.
- Habilita Linux Desktop.
- Incluye Dart SDK.
- Verificación mediante Flutter Doctor.

---

## Scripts

### Instalación

```bash
./01-install.sh
```

### Configuración y verificación

```bash
./02-post-install.sh
```

---

## Comprobación

```bash
flutter --version
dart --version
flutter doctor
```
